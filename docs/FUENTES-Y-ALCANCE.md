# Fuentes, alcance y validaciones pendientes

## Exclusiones deliberadas

No se publican SDK, código propietario, instaladores, información de yacimientos, datos de clientes, credenciales, configuraciones confidenciales ni archivos corporativos no autorizados.
La documentación funcional es una síntesis de la presentación histórica, **no una especificación de software ni un diseño de arquitectura reconstruido**.
